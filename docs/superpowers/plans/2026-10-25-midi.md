# MIDI clips and piano roll implementation plan

Goal: Import .mid/.midi files, create and edit note clips, play them through a selected MIDI output in the existing cue workflow.

Architecture: Extend the existing model and transport; keep MIDI note content embedded in the show. A small modal JUCE piano roll edits a copy and applies atomically. No new dependencies, no synthesizer or video support. Proprietary application license remains unchanged.

Design decisions (developer): MIDI notes only in this first editor, PPQ standard MIDI files 0/1, merge tracks keeping channels, clearly report discarded non-note events. Use cue tempo map, not imported tempo. MIDI notes store beats (quarter notes), duration, pitch, velocity, channel; empty clips default 4 beats. Limit 10000 notes per clip, 4096 beats. MIDI outputs selected by stable identifier; missing device must never reroute silently. Audio device callback supplies common transport timing. Stop/pause/seek/retrigger/panic and output changes must release held notes. No bundled synth; hardware or virtual MIDI receiver provides sound.
